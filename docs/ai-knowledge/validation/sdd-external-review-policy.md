# SDD External Review Policy

External harnesses such as Codex are reviewers, not authorities.

Use external review for:
- design review,
- implementation plan review,
- final diff review,
- suspicious cross-service changes,
- security/sensitive data changes.

The orchestrator must evaluate every external finding:

- accept,
- reject with rationale,
- debate once,
- ask user.

Do not blindly apply external review findings.
Do not reject blocker findings silently.
