## Goal

Edit `pb/demo.proto` to add gift wrap fields to `PlaceOrderRequest` and `OrderResult`, then regenerate all language stubs so downstream task implementers have the updated generated types.

This task is the **foundation gate** for the entire change. Nothing else starts until it is complete.

---

## Scope

### Changes to `pb/demo.proto`

**`PlaceOrderRequest`** — add two fields and guard the pre-existing field-number gap:

```protobuf
message PlaceOrderRequest {
    string user_id = 1;
    string user_currency = 2;
    Address address = 3;
    reserved 4;                    // guard: field 4 was previously unused, prevent accidental reuse
    string email = 5;
    CreditCardInfo credit_card = 6;
    bool   gift_wrap    = 7;       // NEW: user selected gift wrapping
    string gift_message = 8;       // NEW: optional personal message (max 500 chars, frontend-only enforcement)
}
```

**`OrderResult`** — add two fields:

```protobuf
message OrderResult {
    string   order_id              = 1;
    string   shipping_tracking_id  = 2;
    Money    shipping_cost         = 3;
    Address  shipping_address      = 4;
    repeated OrderItem items       = 5;
    bool     gift_wrap             = 6;   // NEW: true if order was gift wrapped
    Money    gift_wrap_cost        = 7;   // NEW: gift wrap fee in user currency (zero if gift_wrap=false)
}
```

Both changes are **backward compatible** (proto3 field additions; existing consumers receive zero/false/nil defaults for new fields).

### Stubs to regenerate

Run: `make docker-generate-protobuf`

This updates:
- `src/checkout/genproto/oteldemo/` (Go)
- `src/frontend/protos/demo.ts` (TypeScript — frontend PlaceOrder call + OrderResult read)
- Python stubs (`src/recommendation/demo_pb2*.py`, `src/product-reviews/demo_pb2*.py`)
- C++ stubs (`src/currency/build/generated/proto/`)

**C# (accounting) and Kotlin (fraud-detection)** regenerate automatically at Docker build time from `pb/demo.proto` — no manual step needed here.

**Node.js runtime (payment)**: loads proto at runtime from `pb/demo.proto`; no explicit code change needed.

**⚠️ react-native-app — manual step required**: `docker-gen-proto.sh` does NOT regenerate
`src/react-native-app/protos/demo.ts`. After running `make docker-generate-protobuf`, copy
the updated `src/frontend/protos/demo.ts` to `src/react-native-app/protos/demo.ts` manually
(the two files track the same generated TypeScript output):

```bash
cp src/frontend/protos/demo.ts src/react-native-app/protos/demo.ts
```

Verify that the copy contains `GiftWrap`, `GiftMessage`, and `GiftWrapCost` field names
before proceeding.
