## Goal

Implement the gift wrap fee calculation and gift message forwarding in `src/checkout/main.go`. The checkout service must:

1. Read `gift_wrap` and `gift_message` from `PlaceOrderRequest`.
2. When `gift_wrap=true`: convert `&pb.Money{Units:5, Nanos:0, CurrencyCode:"USD"}` to user currency; add converted fee to `total` before charging.
3. Set `app.order.gift_wrap` (bool, always — even when false) **early in the span** before `chargeCard`.
4. Set `app.order.gift_wrap.amount` (float64) **after conversion**, only when gift_wrap=true.
5. Emit `span.AddEvent("gift_wrap_fee_applied")` after successful conversion.
6. Sanitize `gift_message` at call site (zero it out when `gift_wrap=false`).
7. Update `sendOrderConfirmation` signature to accept `giftMessage string` as the last parameter.
8. Include `gift_message` in the HTTP JSON body when non-empty.
9. Populate `OrderResult.GiftWrap` and `OrderResult.GiftWrapCost` fields.

**Prerequisite**: T-01 must be complete (generated stubs in `src/checkout/genproto/` must already have the new fields).

## Scope

### Primary file: `src/checkout/main.go`

**Important**: The receiver struct type is `*checkout` (not `*checkoutService`). All snippets below use the correct type.

#### Step 1 — Set `app.order.gift_wrap` span attribute EARLY (before `chargeCard`)

Add to the block at lines 291–294 where `app.user.id` and `app.user.currency` are set, so the attribute is present even if the order fails at payment:

```go
// Add alongside the early span attributes (app.user.id, app.user.currency, etc.)
span.SetAttributes(
    // ... existing attributes ...
    attribute.Bool("app.order.gift_wrap", req.GiftWrap),
    // NOTE: app.order.gift_wrap is intentionally set for both true/false orders.
    // This is required by AC-08 and AC-09 for trace filtering on gift_wrap status.
)
```

#### Step 2 — Declare `giftWrapCostLocalized` at function scope (BEFORE the `if` block)

Declare `giftWrapCostLocalized` OUTSIDE the `if req.GiftWrap` block, so it remains in scope for `OrderResult` construction and the span attribute further down the function:

```go
// Declare at function scope — BEFORE the if req.GiftWrap block
var giftWrapCostLocalized *pb.Money

// === NEW: gift wrap fee conversion ===
if req.GiftWrap {
    giftWrapUSD := &pb.Money{Units: 5, Nanos: 0, CurrencyCode: "USD"}
    convertedFee, err := cs.convertCurrency(ctx, giftWrapUSD, req.UserCurrency)
    if err != nil {
        return nil, fmt.Errorf("failed to convert gift wrap fee: %w", err)
    }
    // NOTE: money.Must panics on CurrencyCode mismatch. This is safe here because
    // convertCurrency returns a Money with CurrencyCode = req.UserCurrency, matching
    // the `total` accumulator (see Assumption A-11). This follows the same pattern
    // used for shipping/items (lines 323-327 of main.go).
    total = money.Must(money.Sum(total, convertedFee))
    giftWrapCostLocalized = convertedFee
    span.AddEvent("gift_wrap_fee_applied")
    // NOTE: "gift_wrap_fee_applied" uses snake_case intentionally for descriptiveness
    // in the workshop context. Existing single-word events ("charged", "shipped") follow
    // a different convention; this is a conscious deviation.

    // Set amount attribute only when gift wrap is true
    giftWrapAmount, _ := strconv.ParseFloat(
        fmt.Sprintf("%d.%02d",
            giftWrapCostLocalized.GetUnits(),
            giftWrapCostLocalized.GetNanos()/1000000000),
        64)
    span.SetAttributes(attribute.Float64("app.order.gift_wrap.amount", giftWrapAmount))
}
```

Insert this block AFTER `prepareOrderItemsAndShippingQuoteFromCart` returns (line 314) and BEFORE `chargeCard` (line 329). Insert it after the existing total accumulation loop (lines 323–327).

**Important about the float formula**: Use `strconv.ParseFloat(fmt.Sprintf("%d.%02d", GetUnits(), GetNanos()/1000000000), 64)` — the same formula used for `app.shipping.amount` and `app.order.amount` at lines 359–360 of `main.go`. Do NOT use `float64(Units) + float64(Nanos)/1e9` which would produce different precision and be inconsistent with existing attributes.

**About `strconv`**: Add `"strconv"` to the import block if not already present.

#### Step 3 — `OrderResult` construction

`giftWrapCostLocalized` is now in scope (declared at function scope above). Use it in the `OrderResult`:

```go
orderResult := &pb.OrderResult{
    OrderId:            orderID.String(),  // use existing orderID variable — do NOT call uuid.New()
    ShippingTrackingId: shippingTrackingID,
    ShippingCost:       prep.shippingCostLocalized,
    ShippingAddress:    req.Address,
    Items:              prep.orderItems,
    GiftWrap:           req.GiftWrap,
    GiftWrapCost:       giftWrapCostLocalized, // nil when gift_wrap=false
}
```

**Note on JSON serialization**: `encoding/json` (used by `sendOrderConfirmation`) does NOT omit nil pointer fields as "absent" — a nil `*pb.Money` becomes `"gift_wrap_cost": null` in the JSON body. The Ruby email service must tolerate `"gift_wrap_cost": null` for non-gift-wrap orders (nil OpenStruct field, same handling as absent key).

#### Step 4 — Call-site sanitization and `sendOrderConfirmation` call

Immediately before calling `sendOrderConfirmation`:

```go
effectiveGiftMessage := ""
if req.GiftWrap {
    effectiveGiftMessage = req.GiftMessage
}
cs.sendOrderConfirmation(ctx, req.Email, orderResult, effectiveGiftMessage)
```

#### Step 5 — Update `sendOrderConfirmation` signature

```go
// Before:
func (cs *checkout) sendOrderConfirmation(ctx context.Context, email string, order *pb.OrderResult) error

// After:
func (cs *checkout) sendOrderConfirmation(ctx context.Context, email string, order *pb.OrderResult, giftMessage string) error
```

**HTTP body construction** — the current function at line 553 already uses `map[string]interface{}`. Extend it:

```go
payload := map[string]interface{}{
    "email": email,
    "order": order,
}
if giftMessage != "" {
    payload["gift_message"] = giftMessage
}
emailPayload, err := json.Marshal(payload)
```

**Important**: Use `otelhttp.Post` for the HTTP call (not plain `http.Post`). The existing `sendOrderConfirmation` uses `otelhttp.Post` to propagate W3C trace context to the email service — this must be preserved after the signature refactor.

## What must NOT change

- `gift_message` must never be set as a span attribute or span event value.
- `gift_message` must never be written to a structured log field (`slog.String`, `slog.Any`, etc.).
- The two existing log calls at the `sendOrderConfirmation` call site (`logger.Warn` / `logger.Info`) must remain exactly as-is. Do NOT add `effectiveGiftMessage` to either format string.
- The `emailPayload` byte slice (which contains `gift_message` when non-empty) must never be logged at any level. No log statement may reference `emailPayload` or `giftMessage` inside `sendOrderConfirmation`.
- `OrderResult` must not carry `gift_message` (it is not a proto field on `OrderResult`).
- The existing `"prepared"` span event must not include `gift_message` text.
- `otelhttp.Post` must be preserved (not replaced with plain `http.Post`) to maintain trace context propagation to the email service.

## Acceptance criteria

1. When `gift_wrap=true`: `OrderResult.GiftWrapCost` is non-nil; equals CurrencyService-converted $5 fee.
2. When `gift_wrap=false`: `OrderResult.GiftWrapCost` is nil; `OrderResult.GiftWrap == false`.
3. `app.order.gift_wrap` (bool) span attribute is set on every order (true and false).
4. `app.order.gift_wrap.amount` span attribute is set only when `gift_wrap=true`.
5. `app.order.gift_wrap` is set BEFORE `chargeCard` (visible on failed-charge spans).
6. `gift_wrap_fee_applied` span event emitted after successful conversion.
7. `gift_message` text does NOT appear in any span attribute or event.
8. `sendOrderConfirmation` HTTP POST body includes `gift_message` when `gift_wrap=true` and message non-empty.
9. `sendOrderConfirmation` HTTP POST body does NOT include `gift_message` when `gift_wrap=false`.
10. `otelhttp.Post` preserved in `sendOrderConfirmation` (not replaced by plain `http.Post`).
11. All existing PlaceOrder tests continue to pass (regression).
12. `go build ./...` and `go test ./...` pass in `src/checkout/`.
