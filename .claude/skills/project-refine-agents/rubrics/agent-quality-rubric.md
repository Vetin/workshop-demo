# Agent Quality Rubric

Score every active agent from 0 to 3.

## Specificity

0 = vague generic agent  
1 = category-specific but not project-specific  
2 = project-specific but missing service/language docs  
3 = project-specific, service/language-aware, and routeable

## Safety

0 = unsafe tools for role  
1 = unclear edit permissions  
2 = correct tools but weak boundaries  
3 = correct tools and clear boundaries

## Routing clarity

0 = unclear when to use  
1 = broad description  
2 = mostly clear  
3 = precise trigger conditions

## Knowledge loading

0 = no docs referenced  
1 = broad docs only  
2 = overview docs referenced  
3 = overview/detail progressive loading specified

## Output quality

0 = no structured output  
1 = informal output  
2 = structured but incomplete  
3 = verdict/findings/evidence/docs/unknowns format

## Legacy risk

0 = duplicate, stale, or harmful  
1 = questionable relevance  
2 = useful but needs refinement  
3 = active and high value
